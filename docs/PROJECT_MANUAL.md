# Component Rules

Every component should:

- Have a single responsibility.
- Be reusable.
- Be typed.
- Never contain hardcoded business data.
- Receive data through props whenever possible.

---

# Design Rules

- Plenty of whitespace.
- Large typography.
- Minimal colors.
- Premium appearance.
- Smooth animations.
- Consistent spacing.

---

# Code Rules

- TypeScript only.
- Functional Components only.
- Named folders.
- No duplicate code.
- No inline styles.
- TailwindCSS only.
