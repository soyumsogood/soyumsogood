# Purpose

This document defines the visual language of the So Yum! So Good! ecosystem.

Every website, application, and future product should follow these standards to ensure a consistent and recognizable experience.

---

# 1. Design Philosophy

Our design should feel:

- Modern
- Premium
- Clean
- Confident
- Human
- Timeless

We avoid unnecessary decoration.

Every visual element must have a purpose.

---

# 2. Design Principles

Every interface should prioritize:

- Simplicity
- Readability
- Consistency
- Accessibility
- Performance

Good design should never distract from the content.

---

# 3. Brand Personality

Our visual identity represents:

- Trust
- Innovation
- Hospitality
- Quality
- Long-term thinking

Everything should feel professionally designed.

---

# 4. Color Philosophy

Colors should communicate hierarchy.

Primary colors represent the brand.

Neutral colors support readability.

Accent colors guide user attention.

Every project inside the ecosystem may have its own brand colors while following the same design principles.

---

# 5. Typography

Typography should always be:

- Clean
- Readable
- Consistent

Hierarchy:

- Display
- Heading
- Subheading
- Body
- Caption

Avoid unnecessary font variations.

---

# 6. Layout

Pages should follow a vertical storytelling structure.

Typical page flow:

Hero

↓

Introduction

↓

Story

↓

Sections

↓

Call to Action

↓

Footer

The user should naturally scroll through the experience.

---

# 7. Spacing

Whitespace is intentional.

Large sections should have generous spacing.

Avoid crowded layouts.

Consistency is more important than density.

---

# 8. Cards

Cards should be:

- Simple
- Consistent
- Easy to scan

Every card should have one primary purpose.

Avoid excessive borders and decoration.

---

# 9. Buttons

Buttons should clearly communicate actions.

Hierarchy:

- Primary
- Secondary
- Text

Avoid using too many button styles.

---

# 10. Images

Images should be:

- High quality
- Authentic
- Brand aligned

Avoid generic stock photography whenever possible.

Images should support the story instead of replacing it.

---

# 11. Icons

Icons should be:

- Simple
- Consistent
- Easy to understand

Do not mix different icon styles.

---

# 12. Animations

Animations should feel:

- Smooth
- Fast
- Purposeful

Animations should enhance usability.

They should never become distractions.

---

# 13. Responsive Design

Every page must work across:

- Mobile
- Tablet
- Laptop
- Desktop

Responsive design is mandatory.

---

# 14. Accessibility

Interfaces should be usable by everyone.

Priorities:

- Readable text
- Sufficient contrast
- Keyboard accessibility
- Clear navigation

Accessibility is part of good design.

---

# 15. Performance

Visual quality should never compromise loading speed.

Optimize:

- Images
- Fonts
- Animations

Fast websites create better experiences.

---

# 16. Consistency

Every new page should feel like part of the same ecosystem.

Users should immediately recognize the So Yum! So Good! identity.

---

# 17. Long-Term Principle

Design systems evolve.

Changes should improve consistency across the ecosystem rather than introducing unnecessary variety.
